# ConceptLab — Interactive Computer Science Learning Website

A complete responsive frontend project for three foundational computer science topics:

1. **Computer Organization and Architecture** — Number Systems Converter
2. **Formal Language and Automata Theory** — DFA string acceptance simulator (even number of `1`s)
3. **Design and Analysis of Algorithms** — Big O complexity growth explorer

## Run locally

No build step or package installation is required.

1. Extract the project ZIP.
2. Open `index.html` in a modern browser.
3. For the best experience, run a local static server (optional), e.g. VS Code Live Server.

## Project structure

- `index.html` — application entry point and dashboard markup
- `styles.css` — responsive layout, theme styling, cards, module pages and mobile styles
- `app.js` — navigation, converter logic, DFA simulation, complexity chart and progress tracker
- `README.md` — project documentation

## Features

- Responsive dashboard and mobile sidebar
- Single-page navigation between modules
- Binary, octal, decimal and hexadecimal conversion
- DFA simulation with state trace and acceptance/rejection result
- Interactive Big O chart with adjustable input size and operation-count cards
- Dark/light appearance toggle
- Exploration progress indicator
- No backend or database required

Google Fonts are loaded from the internet; the website otherwise runs as static frontend files.
